# Саша + Лера

Крути кольцо с постерами — что выпадет, то и смотришь. Фильмы, сериалы и аниме из твоего личного пула.

Приложение лечит вечерний «паралич выбора»: вместо бесконечного скролла каталога ты один раз
собираешь пул «что хочу посмотреть», а потом доверяешь выбор кольцу.

## Что умеет

- **Пул** — ручное добавление позиций: название, тип (фильм / сериал / аниме), ссылка на постер.
  Без постера рисуется аккуратная заглушка с инициалами.
- **Списки** — пул разбит на три списка по типу: «Фильм», «Сериал», «Аниме». Переключатель сверху
  выбирает активный, кольцо крутит только по нему; выбор запоминается. Удобно чередовать: посмотрели
  сериал — переключились на аниме.
- **Автопоиск постера** — кнопка «Найти постер» в карточке: ищет по названию с учётом типа
  (фильм / сериал / аниме) в русской и английской Википедии, AniList (аниме, без ключа) и OMDb
  (если добавил ключ в настройках). Статьи о людях и персонажах отбрасываются, так что на
  «Ганнибала» не придут портреты карфагенского полководца. Показывает варианты, выбираешь
  нужный — ссылка подставляется сама.
- **Кольцо** — до 20 карточек по кругу, вращение с инерцией, указатель сверху.
  Можно нажать «Крутить» или потянуть кольцо и отпустить.
- **Барабан** — если в активном списке больше 20 позиций, кольцо превращается в слот-машину:
  карточки проносятся через указатель, победитель всё равно случаен из всего списка.
- **Выбор** — равномерный рандом внутри активного списка. Одна и та же позиция не выпадает дважды
  подряд, если в списке есть альтернативы. Кольцо не выдаёт то, что смотреть уже нечего: сериал с
  полностью закрытыми вышедшими сезонами в спине не участвует.
- **Сезоны** — у сериала и аниме свой список сезонов со статусами «не вышел / не смотрел / смотрю /
  смотрел / бросил». Так «Монолог Фармацевта» с просмотренными S1–S2 и ещё не существующим S3 не
  выглядит досмотренным, а при выходе нового сезона в истории появляется пометка «вышел S3».
- **После спина** — «Смотрю S2» (сезон в работу, позиция в историю), «Не сейчас» (остаётся в пуле),
  «Не хочу» (в скрытые).
- **Уже смотрел** — в меню позиции в пуле: отмечает все вышедшие сезоны просмотренными и уводит в
  историю, если выпало то, что вы уже видели, или позицию добавили по ошибке.
- **История** — статус выводится из сезонов («смотрю / досмотрел / бросил»), бейдж `S2/4` = следующий
  сезон из вышедших, даты, возврат в пул. «Бросил» не отменяется сам, когда выходит новый сезон.
- **Скрытые** — всё, что отклонил, можно вернуть.
- **Звук** — тиканье колеса и аккорд на остановке, синтез через WebAudio (без медиафайлов). Отключается в шапке.
- **Экспорт / импорт** — резервная копия JSON в настройках.

## Сезоны и прогресс

Фильм — одна отметка «смотрел / не смотрел». У сериала и аниме прогресс ведётся сезон-за-сезоном:

| Статус сезона | Что значит                                                          |
| ------------- | ------------------------------------------------------------------- |
| не вышел      | сезон анонсирован, серий ещё нет — в «вышедшие» не входит           |
| не смотрел    | вышел, но вы до него не дошли                                       |
| смотрю        | сейчас идёт именно этот сезон                                       |
| смотрел       | закрыт                                                              |
| бросил        | закрыт решением «дальше не смотрим»                                 |

- **Статус позиции не хранится, а считается.** Есть сезон «смотрю» → «смотрю»; все вышедшие
  «смотрел» → «досмотрел»; есть вышедший «не смотрел» → «смотрю»; иначе «бросил».
- **Бейдж `S2/4`** — следующий сезон к просмотру и сколько уже вышло (анонсированные не в счёт).
- **Количество сезонов** задаётся при добавлении («сколько сезонов уже вышло»), дальше — в
  меню позиции «Изменить / Сезоны»: статус каждого сезона, «Сезон вышел», «Ещё не вышел», удаление.
- **Номер сезона — это порядок в списке:** удалили S2, бывший S3 стал S2. Удаление сезона с отметкой
  спрашивает подтверждение: прогресс по нему пропадёт.
- **Брошенное остаётся брошенным:** если вышел новый сезон, позиция не возвращается в «смотрю»
  сама — в истории появляется метка «вышел S3», а в меню позиции — действие «Смотрю S3».

## Где живут данные

Только в браузере: `localStorage`, ключ `kinokoltso.v1`, внутри `version: 2`. Сервера нет,
аккаунтов нет, на GitHub Pages уезжает лишь код. Это значит:

- очистишь данные браузера — потеряешь пул и историю;
- на другом устройстве или в другом браузере будет свой пустой пул;
- единственный способ перенести и сохранить — **Настройки → Экспорт** (и потом «Импорт»);
- старые данные (схема v1, где статус висел на тайтле целиком) переносятся автоматически и при
  загрузке, и при импорте бэкапа: `pool/hidden/watching/watched/dropped` превращаются в место
  позиции плюс первый сезон. Ключ хранилища не менялся, так что ничего не теряется.

## Постеры

Источники подбираются автоматически, все запросы идут из браузера:

| Источник | Ключ | Что даёт |
|---|---|---|
| Википедия, русская | не нужен | статья по русскому названию с подсказкой типа («Ганнибал телесериал») |
| Википедия, английская | не нужен | постеры статей и сезонов: в русской Википедии их почти нет |
| AniList | не нужен | обложки аниме высокого качества |
| OMDb | бесплатный ключ | постеры по оригинальному названию, каталог IMDb |

Поиск знает тип позиции: к названию добавляется «фильм», «телесериал» или «аниме», иначе на
запрос «Ганнибал» первыми идут карфагенский полководец и Абрам Ганнибал. Статьи о людях,
персонажах, саундтреках и списках отбрасываются, чужие картинки — тоже: страница должна быть
о фильме или сериале, а картинка — упоминать название. Если в русской статье постера нет (а его
там обычно нет), поиск идёт в английскую статью о том же названии.

Ключ OMDb вводится в **Настройки → Ключ OMDb** и хранится только в этом браузере. Ключ
приходит на почту и требует активации по ссылке из письма — без неё OMDb отвечает
`Invalid API key!`. OMDb запрашивается по оригинальному названию, которое нашлось в Википедии,
поэтому работает и для русских названий.

TMDB здесь не используется: из России `api.themoviedb.org` и `image.tmdb.org` недоступны,
поэтому и API, и сами постеры не загрузятся. Постеры, найденные через Википедию и AniList,
отдаются с `upload.wikimedia.org` и `s4.anilist.co` — они открываются.

Данные о постерах: [Википедия](https://ru.wikipedia.org), [AniList](https://anilist.co),
[OMDb](https://www.omdbapi.com).

## Разработка
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite build → dist/
npm run test     # vitest: мигратор схемы и правила сезонов
npm run preview  # посмотреть собранную версию
```

## Деплой

Пуш в `main` запускает GitHub Actions (`.github/workflows/deploy.yml`): сборка → публикация на GitHub Pages.

Адрес: <https://alexmerf.github.io/carousel-selection/>

База в `vite.config.ts` переключается автоматически: в CI сборка идёт с `/carousel-selection/`,
локально — с `/`.

## Стек

Vite 8 · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui (new-york, тёмная тема, янтарный акцент) ·
WebAudio для звука. Без бэкенда, без роутера, без внешних API.
