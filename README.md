# Кинокольцо

Крути кольцо с постерами — что выпадет, то и смотришь. Фильмы, сериалы и аниме из твоего личного пула.

Приложение лечит вечерний «паралич выбора»: вместо бесконечного скролла каталога ты один раз
собираешь пул «что хочу посмотреть», а потом доверяешь выбор кольцу.

## Что умеет

- **Пул** — ручное добавление позиций: название, тип (фильм / сериал / аниме), ссылка на постер.
  Без постера рисуется аккуратная заглушка с инициалами.
- **Автопоиск постера** — кнопка «Найти постер» в карточке: ищет по названию в Википедии (русские
  названия), AniList (аниме, без ключа) и OMDb (если добавил ключ в настройках). Показывает варианты,
  выбираешь нужный — ссылка подставляется сама.
- **Кольцо** — до 20 карточек по кругу, вращение с инерцией, указатель сверху.
  Можно нажать «Крутить» или потянуть кольцо и отпустить.
- **Барабан** — если в пуле больше 20 позиций, кольцо превращается в слот-машину:
  карточки проносятся через указатель, победитель всё равно случаен из всего пула.
- **Выбор** — фильтр по типу + равномерный рандом. Одна и та же позиция не выпадает дважды подряд,
  если в пуле есть альтернативы.
- **После спина** — «Смотрю» (в историю), «Не сейчас» (остаётся в пуле), «Не хочу» (в скрытые).
- **История** — статусы «смотрю / досмотрел / бросил», даты, возврат в пул.
- **Скрытые** — всё, что отклонил, можно вернуть.
- **Звук** — тиканье колеса и аккорд на остановке, синтез через WebAudio (без медиафайлов). Отключается в шапке.
- **Экспорт / импорт** — резервная копия JSON в настройках.

## Где живут данные

Только в браузере: `localStorage`, ключ `kinokoltso.v1`. Сервера нет, аккаунтов нет,
на GitHub Pages уезжает лишь код. Это значит:

- очистишь данные браузера — потеряешь пул и историю;
- на другом устройстве или в другом браузере будет свой пустой пул;
- единственный способ перенести и сохранить — **Настройки → Экспорт** (и потом «Импорт»).

## Постеры

Источники подбираются автоматически, все запросы идут из браузера:

| Источник | Ключ | Что даёт |
|---|---|---|
| Википедия (ru) | не нужен | постер из карточки статьи, хорошо находит русские названия |
| AniList | не нужен | обложки аниме высокого качества |
| OMDb | бесплатный ключ | постеры по английским названиям, каталог IMDb |

Ключ OMDb вводится в **Настройки → Ключ OMDb** и хранится только в этом браузере.

TMDB здесь не используется: из России `api.themoviedb.org` и `image.tmdb.org` недоступны,
поэтому и API, и сами постеры не загрузятся. Постеры, найденные через Википедию и AniList,
отдаются с `upload.wikimedia.org` и `s4.anilist.co` — они открываются.

Данные о постерах: [Википедия](https://ru.wikipedia.org), [AniList](https://anilist.co),
[OMDb](https://www.omdbapi.com).

## Разработка
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite build → dist/
npm run preview  # посмотреть собранную версию
```

## Деплой

Пуш в `main` запускает GitHub Actions (`.github/workflows/deploy.yml`): сборка → публикация на GitHub Pages.

Адрес: <https://alexmerf.github.io/carousel-selection/>

База в `vite.config.ts` переключается автоматически: в CI сборка идёт с `/carousel-selection/`,
локально — с `/`.

## Стек

Vite 8 · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui (new-york, тёмная тема, янтарный акцент) ·
WebAudio для звука. Без бэкенда, без роутера, без внешних API.
